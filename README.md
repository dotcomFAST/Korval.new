# Korval — landing (concept)

Портфолио-кейс: лендинг вымышленного финтеха Korval в «редакционном» стиле.
Английский язык основной, польский включается переключателем `en / pl` в шапке.

## Файлы в корне репозитория

```
index.html   вся страница: разметка, стили и скрипт в одном файле
hero.jpg     фото hero
team.jpg     фото команды
coins.jpg    портрет с монетами
collar.jpg   портрет с воротником
README.md
```

Фотографии экспортируются из Figma: во фрейме «Korval — Editorial / Desktop 1440 / EN»
выдели слои `hero`, `team`, `coins`, `collar` → панель Export справа (JPG уже настроен) → Export.
Имена файлов должны быть именно такими и лежать рядом с `index.html`, без папок.
Пока фото нет, на их месте видны серые блоки, вёрстка не ломается.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что работает

| Элемент | Поведение |
|---|---|
| `en / pl` | Переводит всю страницу, включая цены (USD ↔ PLN), формат чисел и форму. Выбор запоминается; ссылка `?lang=pl` открывает польскую версию сразу |
| products, pricing, ссылки футера | Плавная прокрутка к разделу |
| Watch demo | Окно с превью видео и переходом к записи на демо |
| Тарифы, «book a demo» | Окно с формой, тариф подставляется автоматически |
| Форма | Проверка полей на текущем языке, экран благодарности |
| Секции | Плавное появление, лёгкий параллакс большой цифры |

Анимации отключаются при системной настройке «Уменьшить движение».

## Доделать перед реальным использованием

- **Отправка формы.** В `index.html` есть закомментированный пример для Formspree — подставь свой ID.
- **Заглушки.** Ссылки с `data-placeholder` (X, Discord, GitHub, LinkedIn, документация, политика, условия) ведут на `#`.
